# Список изменений

## Ангел

Для мифических заклинаний Ангела добавлен крафт:
- можно создавать свитки для всех заклинаний,
- можно создавать зелья для заклинаний Оберег от болезни, Щит от рода демонического, Оберег от нечистот, Оберег от вреда, Оберег от слабости, Эгида верных, Солнечная метка, Благословение мстителя, Возврат и Дар феникса.

## Лич

Для мифических заклинаний Лича добавлен крафт:
- можно создавать свитки для всех заклинаний,
- можно создавать зелья для заклинаний Контроль над плотью, Отвергание смерти и Благословение нежизни.

## Золотой Дракон и Оскверненный Золотой Дракон

Для мифических заклинаний Золотого Дракона и Оскверненного Золотого Дракона добавлен крафт:
- можно создавать свитки для всех заклинаний.

## Эон

Для мифических заклинаний Эона добавлен крафт:
- можно создавать свитки для всех заклинаний,
- можно создавать зелья для заклинаний Кристальный разум, Равная сила, Истинная форма, Совершенное предсказание, Эдикт предопределенности, Эдикт превозмогания, Воплощение порядка, Эдикт неприступной крепости и Совершенство формы.
